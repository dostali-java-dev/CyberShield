## 🚀 OOP Concepts Implemented
* **Encapsulation:** Private attributes with Getters & Setters in `SecurityNode`.
* **Inheritance:** `FirewallSystem` and `AntivirusScanner` extend `SecurityNode` using `super()`.
* **Polymorphism:** Method overriding (`runSecurityCheck()`) across all subclasses.
* **Constructors & Interactive CLI:** Menu-driven control panel using Java `Scanner`.
